## 📂 페이지 구성 및 사용 기술
- **페이지 구성**
  - `index.html` : 프로젝트 소개 및 주요 메뉴 내비게이션 홈 화면
  - `pages/food.html` : 한양대 주변 추천 맛집 가게별 이동 허브 목록
  - `pages/namwol.html` : 남월 쌀국수 안산한양대 본점 상세 소개
  - `pages/myeonsikdang.html` : 면식당 안산한양대점 상세 소개 
  - `pages/bobae.html` : 보배반점 안산한양대점 상세 소개 
  - `css/style.css` : 전체 페이지 공통 스타일시트
- **사용 기술**
  - HTML5 (시맨틱 태그 구조 적용)
  - CSS3 (Flexbox, 반응형 스타일링)
